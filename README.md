# 🎬 Cineflix

API REST desenvolvida com **Java e Spring Boot** para gerenciamento de um catálogo de filmes, categorias e plataformas de streaming.

O projeto foi criado com o objetivo de aprimorar meus conhecimentos em desenvolvimento Back-end, aplicando conceitos de APIs REST, persistência de dados, segurança e organização de código.

## 🚀 Tecnologias utilizadas

- Java 21
- Spring Boot
- Spring Data JPA / Hibernate
- Spring Security + JWT
- PostgreSQL
- Flyway
- Docker e Docker Compose
- Swagger / OpenAPI
- Maven

## ⚙️ Funcionalidades

- CRUD de filmes, categorias e plataformas de streaming
- Relacionamento entre filmes, categorias e streamings
- Busca de filmes por categoria
- Cadastro e autenticação de usuários
- Proteção de endpoints utilizando JWT
- Criptografia de senhas com BCrypt
- Validação de dados e tratamento de exceções
- Documentação interativa da API com Swagger

## 🏗️ Estrutura do projeto

A aplicação está organizada em camadas, separando as responsabilidades:

- **Controller:** gerenciamento das requisições HTTP
- **Service:** regras de negócio
- **Repository:** acesso e persistência dos dados
- **Entity:** entidades do banco de dados
- **DTOs e Mappers:** transferência e conversão de dados
